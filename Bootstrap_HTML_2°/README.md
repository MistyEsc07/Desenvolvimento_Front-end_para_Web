## 📌Sobre o projeto

Este projeto consiste no desenvolvimento de uma página web temática sobre o Dia Internacional da Música, comemorado em 1º de outubro. A proposta é apresentar a importância da música ao longo da história, destacando artistas, períodos históricos e sua influência cultural.

O projeto foi desenvolvido como parte de um treinamento prático de **Bootstrap**, com o objetivo de explorar componentes visuais e aprender a estruturar páginas web de maneira organizada e responsiva.

## 🛠️Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **Bootstrap:** utilização de componentes prontos para a construção do layout e organização dos elementos.
- **Font Awesome:** inclusão de ícones para complementar a interface.

## ✨Funcionalidades e componentes

Durante o desenvolvimento, foram utilizados diferentes componentes para organizar e apresentar as informações:

- **Barra de navegação:** menu com categorias e opções de navegação.
- **Carrossel de imagens:** apresentação de artistas musicais com legendas.
- **Cards:** organização de informações sobre períodos históricos e artistas.
- **Accordion:** exibição de conteúdos em seções expansíveis.
- **Formulário:** campos para nome e e-mail, simulando uma inscrição em newsletter.
- **Ícones:** elementos visuais para complementar os títulos e as seções.
