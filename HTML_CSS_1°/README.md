# 📌 Sobre o projeto

O Lary Equestrian é um projeto de desenvolvimento frontend voltado para o universo do hipismo. A página foi criada com o objetivo de apresentar informações sobre o esporte, seus atletas, curiosidades e a relação entre cavalo e cavaleiro.

O desenvolvimento foi realizado utilizando HTML5 e CSS3, como parte de um treinamento prático de desenvolvimento web. A proposta foi trabalhar a estruturação de uma página desde o início, explorando a organização dos conteúdos, a estilização dos elementos e a criação de uma identidade visual própria.

##🛠️Tecnologias utilizadas

- HTML5: estruturação e organização dos elementos da página.

- CSS3: estilização, cores, tipografia, espaçamentos e efeitos visuais.

## ✨Estrutura e recursos

- O site foi organizado em diferentes seções para facilitar a navegação e apresentar os conteúdos de maneira intuitiva:

- Menu de navegação: permite acessar diretamente as diferentes seções da página.

- Seção inicial (Hero): apresenta uma imagem de destaque como introdução visual.

- Sobre o Hipismo: apresenta informações sobre o esporte e suas principais modalidades.

- Atletas de destaque: reúne imagens e nomes de atletas do cenário equestre.

- Curiosidades: apresenta informações interessantes sobre a história e as características do hipismo.

- Mapa interativo: incorpora o Google Maps para apresentar a localização da Sociedade Hípica Paulista.

- Formulário de contato: possui campos para nome, e-mail e mensagem.

## 🎨 Desenvolvimento visual

A identidade visual foi construída a partir de uma paleta de cores inspirada no universo equestre, utilizando tons de verde, marrom, azul e roxo. No CSS, foram explorados recursos como Flexbox, posicionamento de elementos, imagens de fundo, bordas arredondadas, sombras, transições e efeitos de interação com o cursor (hover). Também foi utilizado o comportamento de rolagem suave (smooth scroll) para tornar a navegação entre as seções mais agradável.
